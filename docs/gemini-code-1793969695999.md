# Crystal (CrystalM2) 1.76 经典石雕底部界面 (HUD) 无损移植与宽屏适配方案

> **2026-11-06 执行注记**：源码实现、图库转换、构建及隔离渲染验证已完成，用户确认后已备份并部署本机，238 项检查通过；服务端未启动，下载包未更新。用户指定的十周年主框实际是 `800×251 / Index 1`，已确认保留原比例；红蓝球共用 `Index 4`，经验条 `Index 7`。下文图号与 C# 代码是原始设计示例，不能直接当作当前实现；实际 API、开关生效方式、布局差异与验证限制见 [README 执行记录](README.md#十周年经典底栏2026-11-06已部署本机)。

> **工程定位**：在 `1366 × 768` 官方最大宽屏下，100% 还原盛大 1.76 经典的**“左日月同辉红蓝大血球 + 中置聊天框与6格药水栏 + 右侧中文石雕圆钮”**底部界面；同时在右侧石雕檐口无缝集成 **1.80 风格【原生 Hero + 坐骑】五枚古铜微控钮**。  
> **解耦原则**：延续单行调用（One-Line Hook）解耦思想[cite: 1]，通过挂载独立的 **`Data/Prguse176.lib`** 图库与新建 **`Classic176HUDLayout.cs`** 布局器实现，**0 破坏原版 `Prguse.lib` / `Prguse2.lib`**，确保五职业技能、装备觉醒、坐骑弹窗等高版本素材 100% 正常显示，且支持一行配置随时切回原版 UI。

## 一、 为什么采用“双图库并存 (`Prguse176.lib`)”架构？

| 方案对比 | 直接替换 `Data/Prguse.lib` | **新增独立 `Data/Prguse176.lib` (本方案)** |
| :--- | :--- | :--- |
| **高版本兼容性** | ❌ 刺客/弓手、坐骑、觉醒、Hero 面板贴图全部丢失黑屏 | ✅ **100% 兼容**（弹窗继续读原版 `Prguse.lib`，仅底部 HUD 读 `Prguse176.lib`） |
| **底部中文汉化** | 需手动修图 | ✅ **天然纯正中文**（盛大 1.76 石雕按钮本身自带汉字刻度） |
| **可逆性与维护** | 覆盖后难以还原 | ✅ `Settings.UseClassic176HUD = true/false` **一键热切换** |

## 二、 1366×768 宽屏下的 1.76 底栏布局设计

原版 1.76 石雕底栏总宽度为 **`800px`**。在 **`1366 × 768`** 宽屏下，若强行横向拉伸会导致红蓝血球变成椭圆、石雕汉字严重变形。因此我们采用 **“800px 原生比例居中坞站 + 1.80式英雄微控栏 + 左右视野留白（或黑金护翼）”** 布局：

```text
+--------------------------------------- 1366 px 宽屏视野 ---------------------------------------+
|                                                                                               |
|                                       [ 主游戏地图渲染区 ]                                      |
|                                    (主号 + 原生 Hero 双控区)                                   |
|                                                                                               |
|                            [6格药水快捷栏 BeltDialog]     [英雄: 召 | 装 | 包 | 模 | 骑]       |
|  (左侧 283px 视野留白区)  +---------------------------------------------------------------+     |
|  可斜下角提前发现怪物    | (左红HP/右蓝MP) |     1.76 经典聊天框      | 装 状 包 技 声 退 |     |
|  或挂载黑金坐标/攻速铭牌 |   日月同辉大球   |     (ChatDialog)         | 易 组 会 图 (石雕)|     |
+--------------------------+-----------------+--------------------------+-------------------+-----+
                           |<---------------- 800 px (居中 X=283 ~ 1083) ------------------>|
```

## 三、 Step 1：使用 `LibraryEditor` 制作 `Prguse176.lib`（耗时 3 分钟）

1. **提取盛大 1.76 原始文件**：从任意国内盛大 1.76 / 1.80 客户端的 `Data/` 目录中，复制出 **`Prguse.wil`** 和 **`Prguse.wix`**（如果是新格式则为 `Prguse.wzl` 和 `Prguse.wzx`）。
2. **使用内置工具一键转换**：
   * 编译并运行 Crystal 解决方案自带的 **`LibraryEditor.exe`**。
   * 点击顶部菜单 **`Convert` -> `WIL/WZL to LIB`**，选中刚复制出来的 `Prguse.wil`。
   * 将转换生成的 `.lib` 文件重命名为 **`Prguse176.lib`**，放入你的 Crystal 客户端 **`Data/Prguse176.lib`** 路径下。
3. **核心素材在 `Prguse176.lib` 中的标准图号（Index）速查表**：
   *(注：不同年代的盛大客户端可能会有几十号的微小偏移，可在 `LibraryEditor` 中打开 `Prguse176.lib` 一眼核对前 80 张图)*

| UI 部件名称 | 盛大 1.76 标准图号 (`Index`) | 尺寸与用途说明 |
| :--- | :--- | :--- |
| **底部石雕主框架** | `Index = 0` (或 `1`) | `800 × 144` 像素，包含左侧球槽、中间聊天框外沿、右侧石雕底座 |
| **左半圆红血球 (HP)** | `Index = 4` | 左半边红色球体，配合 `DrawSection` 自下而上按 HP 百分比裁剪 |
| **右半圆蓝魔球 (MP)** | `Index = 5` | 右半边蓝色球体，配合 `DrawSection` 自下而上按 MP 百分比裁剪 |
| **经验值绿/黄进度条** | `Index = 8` | 位于底栏最下沿的细长经验刻度条 |
| **6格喝药腰带框** | `Index = 9` (或 `10`) | 悬浮在聊天框左上方的 6 格药水石雕槽 |
| **右侧 6 大石雕主按钮** | `Index = 12 ~ 29` | 依次为：装备(人)、状态、背包、技能、声音、退出（每组含常态/悬停/按下） |
| **右侧 4 枚石雕小按钮** | `Index = 30 ~ 41` | 依次为：交易、组队、行会、小地图 |

## 五、 Step 3：新建 1.76 底部界面适配器 (`Client/MirControls/Classic176HUDLayout.cs`)

为了不把原有的 `MainDialogs.cs` 改得面目全非，我们在 `Client/MirControls/` 下新建 **`Classic176HUDLayout.cs`**，集中接管 `MainDialog`、`ChatDialog`、`BeltDialog` 的重定位、红蓝大球裁剪绘制，以及 **1.80 风格 Hero 快捷栏** 的生成：

```csharp
using System;
using System.Drawing;
using System.Windows.Forms;
using Client.MirGraphics;
using Client.MirObjects;
using Client.MirScenes;
using Client.MirScenes.Dialogs;
using Shared;

namespace Client.MirControls
{
    /// <summary>
    /// 1.76 经典石雕底部界面 (HUD) 无损重构与 Hero 扩展坞适配器
    /// </summary>
    public static class Classic176HUDLayout
    {
        // ===== 1.76 Prguse176.lib 核心图号配置区 (若你的 .wil 版本图号有偏差，仅需改这几个数字) =====
        private const int IDX_MAIN_FRAME = 0;   // 800px 底部石雕主框架
        private const int IDX_HP_ORB     = 4;   // 左半圆红血球 (HP)
        private const int IDX_MP_ORB     = 5;   // 右半圆蓝魔球 (MP)
        private const int IDX_EXP_BAR    = 8;   // 底部经验条
        private const int IDX_BELT_FRAME = 9;   // 6格药水栏背景框

        // 右侧石雕按钮图号 (常态 Index, 按下 PressedIndex)
        private const int IDX_BTN_CHAR   = 12;  // [装备/人物] (F10)
        private const int IDX_BTN_STATE  = 14;  // [状态]
        private const int IDX_BTN_BAG    = 16;  // [背包] (F9)
        private const int IDX_BTN_SKILL  = 18;  // [技能] (F11)
        private const int IDX_BTN_SOUND  = 20;  // [声音/设置]
        private const int IDX_BTN_EXIT   = 22;  // [退出/小退]

        /// <summary>
        /// 在 GameScene 初始化末尾单行调用，一键将底部 UI 转换为 1.76 经典石雕形态
        /// </summary>
        public static void Apply176BottomHUD(GameScene scene)
        {
            if (!Settings.UseClassic176HUD || scene?.MainDialog == null) return;

            var main = scene.MainDialog;

            // 1. 切换底部主框架为 Prguse176.lib 并水平居中贴底 (1366x768 下 X = 283)
            main.Library = Libraries.Prguse176;
            main.Index = IDX_MAIN_FRAME;
            main.Size = new Size(800, 144);
            int baseX = (Settings.ScreenWidth - 800) / 2;
            int baseY = Settings.ScreenHeight - main.Size.Height;
            main.Location = new Point(baseX, baseY);

            // 隐藏原版 Euro Mir 不兼容的零散贴图控件
            if (main.HealthBar != null) main.HealthBar.Visible = false;
            if (main.ManaBar != null) main.ManaBar.Visible = false;
            if (main.ExperienceBar != null) main.ExperienceBar.Visible = false;

            // 2. 构建 1.76 灵魂：【左红右蓝・日月同辉大血球】(自下而上动态水位裁剪)
            SetupClassicSunMoonOrbs(main);

            // 3. 重定位中间【经典聊天框 ChatDialog】与上方【6格药水栏 BeltDialog】
            AlignChatAndBeltDialogs(scene, baseX, baseY);

            // 4. 重映射右侧【1.76 汉字石雕按钮组】
            RemapRightStoneButtons(main);

            // 5. 在右侧石雕檐口挂载【1.80 风格：原生 Hero + 坐骑 + 猎魔手札】古铜控制栏
            BuildHeroAndExtensionDock(scene, main);

            // 6. 在 1366 宽屏左右留白处挂载【低压暗金护翼状态铭牌】(填补 800px 两侧黑边)
            BuildWidescreenSideWings(scene, baseX);
        }

        /// <summary>
        /// 自下而上动态水位裁剪渲染 1.76 左红(HP)右蓝(MP)大血球与底部经验条
        /// </summary>
        private static void SetupClassicSunMoonOrbs(MainDialog main)
        {
            var orbCanvas = new MirControl
            {
                Parent = main,
                Location = new Point(10, 26), // 对齐左下角石雕圆形凹槽
                Size = new Size(104, 104),
                NotControl = true
            };

            orbCanvas.AfterDraw += (s, e) =>
            {
                if (MapObject.User == null || Libraries.Prguse176 == null) return;

                // --- A. 绘制左半圆 HP 红球 ---
                double hpPct = Math.Clamp(MapObject.User.HP / (double)Math.Max(1, MapObject.User.MaxHP), 0.0, 1.0);
                if (hpPct > 0)
                {
                    Size hpSize = Libraries.Prguse176.GetSize(IDX_HP_ORB);
                    int drawH = (int)(hpSize.Height * hpPct);
                    int yOff = hpSize.Height - drawH;
                    Libraries.Prguse176.DrawSection(
                        IDX_HP_ORB,
                        new Point(orbCanvas.DisplayRectangle.X, orbCanvas.DisplayRectangle.Y + yOff),
                        new Rectangle(0, yOff, hpSize.Width, drawH),
                        Color.White, false);
                }

                // --- B. 绘制右半圆 MP 蓝球 ---
                double mpPct = Math.Clamp(MapObject.User.MP / (double)Math.Max(1, MapObject.User.MaxMP), 0.0, 1.0);
                if (mpPct > 0)
                {
                    Size mpSize = Libraries.Prguse176.GetSize(IDX_MP_ORB);
                    int drawH = (int)(mpSize.Height * mpPct);
                    int yOff = mpSize.Height - drawH;
                    // 右半圆贴合在左半圆右侧 (X 偏移约 48px)
                    Libraries.Prguse176.DrawSection(
                        IDX_MP_ORB,
                        new Point(orbCanvas.DisplayRectangle.X + 48, orbCanvas.DisplayRectangle.Y + yOff),
                        new Rectangle(0, yOff, mpSize.Width, drawH),
                        Color.White, false);
                }

                // --- C. 绘制底部 1.76 经验进度条 ---
                double expPct = Math.Clamp(MapObject.User.Experience / (double)Math.Max(1, MapObject.User.MaxExperience), 0.0, 1.0);
                if (expPct > 0)
                {
                    Size expSize = Libraries.Prguse176.GetSize(IDX_EXP_BAR);
                    int drawW = (int)(expSize.Width * expPct);
                    Libraries.Prguse176.DrawSection(
                        IDX_EXP_BAR,
                        new Point(main.DisplayRectangle.X + 148, main.DisplayRectangle.Y + 131),
                        new Rectangle(0, 0, drawW, expSize.Height),
                        Color.White, false);
                }
            };

            // 血球上方直观显示 HP / MP 数字与等级
            var hpMpLabel = new MirLabel
            {
                Parent = main,
                AutoSize = false,
                Size = new Size(110, 18),
                Location = new Point(8, 6),
                DrawFormat = TextFormatFlags.HorizontalCenter | TextFormatFlags.VerticalCenter,
                ForeColour = Color.FromArgb(255, 240, 220, 180),
                Font = new Font(Settings.FontName, 8F, FontStyle.Bold),
                NotControl = true
            };
            hpMpLabel.BeforeDraw += (s, e) =>
            {
                if (MapObject.User != null)
                    hpMpLabel.Text = $"{MapObject.User.HP}/{MapObject.User.MaxHP}  {MapObject.User.MP}/{MapObject.User.MaxMP}";
            };
        }

        /// <summary>
        /// 将聊天框 (ChatDialog) 嵌入 1.76 石雕主框中央，并将 6 格喝药栏置于其正上方
        /// </summary>
        private static void AlignChatAndBeltDialogs(GameScene scene, int baseX, int baseY)
        {
            if (scene.ChatDialog != null)
            {
                var chat = scene.ChatDialog;
                // 嵌入 800px 石雕框的中间凹槽区 (相对 X: 145, 宽: 465, 高: 115)
                chat.Location = new Point(baseX + 145, baseY + 16);
                chat.Size = new Size(465, 115);
            }

            if (scene.BeltDialog != null)
            {
                var belt = scene.BeltDialog;
                belt.Library = Libraries.Prguse176;
                belt.Index = IDX_BELT_FRAME;
                // 悬浮于石雕聊天框正上方偏左位置
                belt.Location = new Point(baseX + 150, baseY - belt.Size.Height + 6);
            }
        }

        /// <summary>
        /// 将右侧功能按钮重映射到 Prguse176 的中文石雕按钮图号与坐标
        /// </summary>
        private static void RemapRightStoneButtons(MainDialog main)
        {
            void SetStoneBtn(MirButton btn, int idx, int x, int y)
            {
                if (btn == null) return;
                btn.Library = Libraries.Prguse176;
                btn.Index = idx;
                btn.HoverIndex = idx;
                btn.PressedIndex = idx + 1;
                btn.Location = new Point(x, y);
                btn.Visible = true;
            }

            // 右侧上排/下排 6 大核心石雕圆钮 (相对 800px 主框的 X, Y 坐标)
            SetStoneBtn(main.CharacterButton, IDX_BTN_CHAR,  632, 34); // 装(F10)
            SetStoneBtn(main.StatusButton,    IDX_BTN_STATE, 682, 34); // 状
            SetStoneBtn(main.InventoryButton, IDX_BTN_BAG,   732, 34); // 包(F9)
            SetStoneBtn(main.SkillButton,     IDX_BTN_SKILL, 632, 82); // 技(F11)
            SetStoneBtn(main.OptionButton,    IDX_BTN_SOUND, 682, 82); // 设(F12)
            SetStoneBtn(main.MenuButton,      IDX_BTN_EXIT,  732, 82); // 菜单/退
        }

        /// <summary>
        /// 复刻 1.80 英雄版：在右侧石雕面板顶部檐口生成 5 枚古铜微控按钮（专管原生 Hero 与全版本功能）
        /// </summary>
        private static void BuildHeroAndExtensionDock(GameScene scene, MainDialog main)
        {
            string[] labels = { "召英", "英包", "英装", "任务", "坐骑" };
            Action[] actions =
            {
                // 1. 召唤/收起原生 Hero
                () => MirNetwork.Network.Enqueue(new ClientPackets.CallHero()),
                // 2. 打开/关闭英雄背包
                () => { if (scene.HeroInventoryDialog != null) scene.HeroInventoryDialog.Visible = !scene.HeroInventoryDialog.Visible; },
                // 3. 打开/关闭英雄装备栏
                () => { if (scene.HeroCharacterDialog != null) scene.HeroCharacterDialog.Visible = !scene.HeroCharacterDialog.Visible; },
                // 4. 打开任务日志
                () => { if (scene.QuestDialog != null) scene.QuestDialog.Visible = !scene.QuestDialog.Visible; },
                // 5. 打开坐骑面板 (或上下马)
                () => { if (scene.MountDialog != null) scene.MountDialog.Visible = !scene.MountDialog.Visible; }
            };

            for (int i = 0; i < labels.Length; i++)
            {
                int idx = i;
                var stoneTab = new MirControl
                {
                    Parent = main,
                    Size = new Size(34, 20),
                    Location = new Point(622 + i * 36, 4), // 整齐排列在右侧石雕顶部凹槽
                    BackColour = Color.FromArgb(245, 32, 27, 21),
                    DrawControlTexture = true,
                    Border = true,
                    BorderColour = Color.FromArgb(220, 110, 92, 65)
                };

                var lbl = new MirLabel
                {
                    Parent = stoneTab,
                    AutoSize = false,
                    Size = stoneTab.Size,
                    Location = new Point(0, -1),
                    DrawFormat = TextFormatFlags.HorizontalCenter | TextFormatFlags.VerticalCenter,
                    ForeColour = Color.FromArgb(255, 230, 205, 155),
                    Font = new Font(Settings.FontName, 8F, FontStyle.Bold),
                    Text = labels[i],
                    NotControl = true
                };

                stoneTab.MouseEnter += (s, e) => lbl.ForeColour = Color.Gold;
                stoneTab.MouseLeave += (s, e) => lbl.ForeColour = Color.FromArgb(255, 230, 205, 155);
                stoneTab.Click += (s, e) => actions[idx]?.Invoke();
            }
        }

        /// <summary>
        /// 在 1366 宽屏底部左右两侧 (各 283px) 生成与石雕等高的古朴状态铭牌（显示地图名、坐标、背包负重）
        /// </summary>
        private static void BuildWidescreenSideWings(GameScene scene, int sideWidth)
        {
            if (sideWidth <= 20) return;

            // 左下角贴底铭牌：实时显示当前地图名、精确坐标与时间
            var leftWing = new MirControl
            {
                Parent = scene,
                Size = new Size(sideWidth, 28),
                Location = new Point(0, Settings.ScreenHeight - 28),
                BackColour = Color.FromArgb(235, 18, 16, 14),
                DrawControlTexture = true,
                Border = true,
                BorderColour = Color.FromArgb(180, 85, 72, 52),
                NotControl = true
            };

            var mapCoordLabel = new MirLabel
            {
                Parent = leftWing,
                AutoSize = false,
                Size = leftWing.Size,
                DrawFormat = TextFormatFlags.HorizontalCenter | TextFormatFlags.VerticalCenter,
                ForeColour = Color.FromArgb(255, 220, 200, 160),
                Font = new Font(Settings.FontName, 8.5F, FontStyle.Bold),
                NotControl = true
            };
            mapCoordLabel.BeforeDraw += (s, e) =>
            {
                if (MapObject.User != null && scene.MapControl != null)
                    mapCoordLabel.Text = $"{scene.MapControl.Title} [{MapObject.User.CurrentLocation.X} : {MapObject.User.CurrentLocation.Y}]";
            };

            // 右下角贴底铭牌：实时显示人物负重、金币数量与经验百分比
            var rightWing = new MirControl
            {
                Parent = scene,
                Size = new Size(sideWidth, 28),
                Location = new Point(Settings.ScreenWidth - sideWidth, Settings.ScreenHeight - 28),
                BackColour = Color.FromArgb(235, 18, 16, 14),
                DrawControlTexture = true,
                Border = true,
                BorderColour = Color.FromArgb(180, 85, 72, 52),
                NotControl = true
            };

            var statsWingLabel = new MirLabel
            {
                Parent = rightWing,
                AutoSize = false,
                Size = rightWing.Size,
                DrawFormat = TextFormatFlags.HorizontalCenter | TextFormatFlags.VerticalCenter,
                ForeColour = Color.FromArgb(255, 220, 200, 160),
                Font = new Font(Settings.FontName, 8.5F, FontStyle.Regular),
                NotControl = true
            };
            statsWingLabel.BeforeDraw += (s, e) =>
            {
                if (MapObject.User != null)
                {
                    double expPct = MapObject.User.Experience * 100.0 / Math.Max(1, MapObject.User.MaxExperience);
                    statsWingLabel.Text = $"金币: {GameScene.Gold:N0}   EXP: {expPct:F1}%";
                }
            };
        }
    }
}
```

## 六、 Step 4：在 `GameScene.cs` 中挂载单行调用 (One-Line Hook)

打开 **`Client/MirScenes/GameScene.cs`**，在构造函数 `public GameScene()` 的最底部（即紧挨着上一轮挂载的 `ChineseUIOverlay.ApplyToGameScene(this);` 下方），加上 1 行调用代码：


## 七、 图号与坐标 10 秒微调校准法

由于市面上流传的盛大 1.76 客户端（如 2003 原版 `Prguse.wil` vs 十周年客户端 `Prguse.wzl`）内部图片序号可能存在几张图的偏差：

1. **核对 6 个常量图号**：打开 `LibraryEditor` 加载你转出来的 `Data/Prguse176.lib`，看前 30 张图，把 **底框 (`IDX_MAIN_FRAME`)、左红球 (`IDX_HP_ORB`)、右蓝球 (`IDX_MP_ORB`)、经验条 (`IDX_EXP_BAR`)、6格腰带 (`IDX_BELT_FRAME`)** 的实际序号填进 `Classic176HUDLayout.cs` 顶部的 `const int` 常量区。
2. **用 `Alt` 坐标尺微调按钮位置**：如果某个石雕按钮偏了几个像素，直接在 `Apply176BottomHUD` 末尾加一行上一轮写的 `ChineseUIOverlay.EnableCoordInspector(main, "176底栏");`，进游戏按住 **`Alt` 键** 把鼠标移到石雕底图的按钮凹槽上，左下角就会直接报出精确的 `(X, Y)` 坐标，填入 `RemapRightStoneButtons` 即可严丝合缝！
