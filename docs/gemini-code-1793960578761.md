# Crystal (CrystalM2) 全版本・单人+原生Hero 慢节奏养老服终极工程方案 (v4.0 融合版)

> **版本定位**：Euro Mir 全版本全特性开启（战/法/道/刺/弓五职业 + 原生 Hero 副将 + 坐骑/觉醒/插槽 + 1~65级全地图）  
> **架构铁律**：新建独立的 **`Crystal.SoloExtension`** 命名空间，原版代码仅插入极简的 **One-Line Hook（单行调用）**；所有扩展数据采用 **`Envir/SoloData/Solo_{角色名}.json` 旁路存储**，对原生 `Server.MirDB` 与 `Users.MirDB` 零结构改动、零坏档风险。  
> **画面与交互**：锁定官方最大原生宽屏 **`1366 × 768`**；全代码层中文汉化 + **C# 渲染层“黑金铭牌遮罩” (`ChineseUIOverlay.cs`)**，零 `.lib` 解包修改。  
> **生命周期**：300 ~ 500+ 小时（4 ~ 6 个月硬核慢节奏养成）。

## 一、 全局基础配置 (`Setup.ini`) 与物理法则

## 二、 架构规范：`Crystal.SoloExtension` 解耦目录与 8 处单行 Hook

在 `Server` 项目下新建文件夹 **`SoloExtension`**（命名空间 `Server.SoloExtension`），将所有新增玩法与原生代码彻底隔离：

```text
Server/
├── MirObjects/                    # [原生目录] 仅插入 8 处 One-Line Hook
├── MirEnvir/                      # [原生目录] 仅插入字典汉化与惊扰度 Hook
└── SoloExtension/                 # 【新建独立扩展目录】
    ├── SoloExtensionHost.cs       # 唯一静态门面入口
    ├── SoloPlayerProfile.cs       # 旁路 JSON 存档 (Envir/SoloData/Solo_{Name}.json)
    ├── EcologyAndRarityModule.cs  # 四阶变异(变异/精英/统领/红名领主)、惊扰度、两段式禁回血AI
    ├── TownAndCampModule.cs       # 【玛法行军帐】扎营返场、【军需官】主英一键统卖(锁极品)与特修
    └── HunterTomeModule.cs        # 【玛法猎魔手札】(范围拾取、本图领主感知、怪物图鉴永久属性)
```

### 原版服务端代码中的 8 处单行挂载点 (One-Line Hooks)

| 序号 | 原版文件与方法位置 | 插入的单行调用代码 (`using Server.SoloExtension;`) | 核心作用 |
| :--- | :--- | :--- | :--- |
| **1** | `Envir.cs` $\rightarrow$ `Start()` (在 `LoadDrops()` 之后) | `SoloExtensionHost.ApplyInGameChinese(this);` | 内存挂载 `ChineseNames.txt`，汉化怪物、地图、技能与物品 `FriendlyName` |
| **2** | `PlayerObject.cs` $\rightarrow$ `GainExp(uint amount)` 开头 | `if (SoloExtensionHost.TryHandleCustomExp(this, amount)) return;` | 接管 **1~65级六段式经验衰减** 与 **主号(75%)+Hero(45%) 经验分流** |
| **3** | `PlayerObject.cs` $\rightarrow$ `Process()` 每秒心跳处 | `SoloExtensionHost.OnPlayerTick(this);` | 驱动 **$4\times4$ 范围自动拾取** 与 图鉴属性同步 |
| **4** | `PlayerObject.cs` $\rightarrow$ `UseItem(UserItem item)` | `if (SoloExtensionHost.TryUseCustomItem(this, item)) return;` | 双击 **【玛法行军帐】** 或 **【玛法猎魔手札】** 弹出古朴交互对话框 |
| **5** | `NPCObject.cs` $\rightarrow$ `Call(PlayerObject player, string key)` | `if (SoloExtensionHost.TryHandleNpcAction(player, key)) return;` | 处理 `@Solo_QuickSell`（统卖锁极品）、`@Solo_QuickRepair`（主英全身特修）、`@Camp_*` |
| **6** | `MonsterObject.cs` $\rightarrow$ `Spawn()` / `RefreshAll()` 末尾 | `SoloExtensionHost.OnMonsterSpawn(this);` | 执行四阶变异（`[变异]`/`[精英]`/`[统领]`/`[领主]`）与功能副词条染色 |
| **7** | `MonsterObject.cs` $\rightarrow$ `ProcessAI()` 心跳处 | `SoloExtensionHost.OnMonsterTick(this);` | 触发红名 **`[领主]`** 接敌警报、**50%血量召亲卫**、**20%残血狂暴且禁绝自然回血** |
| **8** | `MonsterObject.cs` $\rightarrow$ `Die()` / `Drop()` 处 | `SoloExtensionHost.OnMonsterKilled(this, EXPOwner);` | 累加 **地图惊扰度(Map Heat)**（满50出精英/满100刷猩红领主）、执行连爆与四阶词条反向定级 |

## 三、 专项一：L1 道具/NPC 媒介化减负与三合一重铸 (`TownAndCampModule.cs`)

摒弃破坏沉浸感的 `@move` 命令，所有减负均通过游戏内实体道具与城镇 NPC 完成：

### 3.1 四大核心交互媒介
1. **【玛法行军帐】（洞穴扎营 + 安全区返场，保留回城卷价值）**
   * **野外/洞穴双击**：弹出面板选择 `[在此处升起篝火扎营/@Camp_Set]`，消耗 $2,000$ 金币记录当前坐标至玩家的 `Solo_{Name}.json`（**石墓七层、祖玛教主之家、赤月魔穴、冰宫底层等终极 Boss 房禁止扎营**，仅允许在上一层扎营）。
   * **回城方式**：行军帐**不提供**野外直接回城功能，玩家回城必须使用经典的 **【回城卷 / 地牢逃脱卷】**。
   * **安全区双击**：在比奇/盟重安全区双击行军帐，点击 `[整理行装，返回营地/@Camp_Return]`，瞬间携 Hero 传回洞穴营地继续开荒。
2. **【玛法军需官 NPC】（跨店一键统卖 + 极品自动锁死 + 主英全身特修）**
   * **`[一键出售普通战利品/@Solo_QuickSell]`**：自动遍历主号背包，将未鉴定的普通白板装备按商店价批量结算为金币。**极品锁死铁律**：凡是品质 $\ge$ `Uncommon`（`【精良】`及以上）、带有任何极品附加点、带幸运/暴击/吸血/插槽、或属于沃玛及以上名牌装备，**100% 自动跳过保护**，并在聊天框绿字汇报结算明细。
   * **`[主号与英雄全身特修/@Solo_QuickRepair]`**：一键特修主号与 Hero 身上穿戴的所有装备（免去全身扒下来一件件点修理的繁琐）。
3. **【玛法猎魔手札】（随身 0 重量永久奇物）**
   * 双击打开古朴面板：可一键切换 **`[4×4 范围自动拾取]`**（全部拾取 / 仅拾取金币药水与精良以上极品）、点击 **`[感知本层魔物惊扰度]`**（显示当前地图惊扰度进度如 `76/100` 及存活的 `[领主]` 方位）、查看 **`[玛法猎魔图鉴]`**（累计击杀指定数量白野猪/祖玛卫士永久增加人物攻魔道或爆率）。
4. **【盟重神匠：同名装备三合一重铸】**
   * 主号穿剩给 Hero，Hero 淘汰下来的同名沃玛/祖玛/赤月装备，每 **3 件同名装备 + 金币** 可重铸为 1 件必带极品词条的新装备，有概率直接洗出鲜红色的 **【神话・传世】** 孤品。

## 四、 专项二：四阶生态融合 + 地图惊扰度 + 两段式领主 AI (`EcologyAndRarityModule.cs`)

将游戏原生的 `Uncommon / Rare / Elite` 与新增的最高阶鲜红 `Lord` 深度统一，怪物使用**生态威慑名**，装备使用**品质名**，并引入功能性副词条与地图惊扰度：

### 4.1 怪物与装备四阶统一映射表

| 枚举等级 (`Rarity`/`Grade`) | 怪物头顶名称与功能变种 | 装备品质定名 | 视觉代表色 (`Color`) | 自然刷新率 + 惊扰度保底 | 属性倍率 & 死亡连爆 (`dropLoops`) | 词条生成规则（反向决定装备品质） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`0: None`** | `白野猪` | 普通 | 白色 `White` | `96.35%` (每杀1只+3惊扰度) | `1.0x` 血攻 / **1 轮** | `8%` 概率出 1 条基础属性 |
| **`1: Uncommon`** | **`[变异]白野猪`** | **`【精良】`** | 翠绿 `LimeGreen` | `2.50%` | `2.0x` 血 / `1.2x` 攻 / **2 轮** | 必出 1 条 (`+1~+3`)；总点数 `1~2` 定为 **【精良】** |
| **`2: Rare`** | **`[精英・富饶]`** (金)<br>**`[精英・坚韧]`** (绿)<br>**`[精英・狂暴]`** (橙) | **`【稀有】`** | 天蓝 `DeepSkyBlue`<br>*(富饶变种为亮金)* | `0.80%` + **惊扰度满 50 必出** | `3.5x` 血 / `1.35x` 攻 / **3 轮**<br>*(富饶必爆金币堆；坚韧必掉黑铁矿)* | 必出 1~2 条 (`+2~+4`)；总点数 `3~4` 定为 **【稀有】** |
| **`3: Elite`** | **`[统领]白野猪`** | **`【史诗】`** | 暗金 `Gold` | `0.25%` | `5.5x` 血 / `1.6x` 攻 / **5 轮** | 必出 2~3 条 (`+2~+5`，30%出暴击/吸血)；总点数 `5~7` 定为 **【史诗】** |
| **`4: Lord` [新增]** | **`[领主]血煞白野猪`** | **`【神话・传世】`** | **猩红 `Crimson`** | `0.10%` + **惊扰度满 100 必出** | **`9.0x` 血 / `1.9x` 攻 / 破隐 / 8 轮大爆** | 必出 3 条 (`+3~+6`，65%出特殊词条)；**带特殊词条且总点$\ge 6$ 定为【神话】** |

### 4.2 核心 C# 实现：`SoloExtension/EcologyAndRarityModule.cs`

```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using Server.MirObjects;
using Server.MirEnvir;
using Shared;
using S = ServerPackets;

namespace Server.SoloExtension
{
    public static class EcologyAndRarityModule
    {
        // 记录每张地图当前的杀戮惊扰度 (Map Heat: 0 ~ 100)
        private static readonly Dictionary MapHeatDict = new Dictionary();

        // 1. 怪物生成时的四阶变异判定
        public static void OnMonsterSpawn(MonsterObject mob, MonsterRarity? forcedRarity = null)
        {
            if (mob.Info.AI == 6 || mob.Info.Boss || mob.Master != null || mob.Info.HP >= 15000)
            {
                mob.Rarity = MonsterRarity.None;
                return;
            }

            if (forcedRarity.HasValue)
            {
                mob.Rarity = forcedRarity.Value;
            }
            else
            {
                int roll = Envir.Main.Random.Next(10000);
                if (roll < 10)       mob.Rarity = MonsterRarity.Lord;     // 0.10% 猩红[领主]
                else if (roll < 35)  mob.Rarity = MonsterRarity.Elite;    // 0.25% 暗金[统领]
                else if (roll < 115) mob.Rarity = MonsterRarity.Rare;     // 0.80% 天蓝[精英]
                else if (roll < 365) mob.Rarity = MonsterRarity.Uncommon; // 2.50% 翠绿[变异]
                else                 mob.Rarity = MonsterRarity.None;
            }

            switch (mob.Rarity)
            {
                case MonsterRarity.Uncommon:
                    mob.Name = $"[变异]{mob.Info.GameName}";
                    mob.NameColour = Color.LimeGreen;
                    mob.MaxHP = (uint)(mob.Info.HP * 2.0);
                    mob.MaxDC = (ushort)(mob.Info.MaxDC * 1.20);
                    break;

                case MonsterRarity.Rare:
                    // 随机赋予三大功能性副词条：[富饶](必爆大堆金币)、[坚韧](必掉纯度15+黑铁)、[狂暴](高攻掉武器)
                    int subType = Envir.Main.Random.Next(3);
                    string tag = subType == 0 ? "精英・富饶" : (subType == 1 ? "精英・坚韧" : "精英・狂暴");
                    mob.Name = $"[{tag}]{mob.Info.GameName}";
                    mob.NameColour = subType == 0 ? Color.Gold : (subType == 1 ? Color.MediumSpringGreen : Color.DeepSkyBlue);
                    mob.MaxHP = (uint)(mob.Info.HP * 3.5);
                    mob.MaxDC = (ushort)(mob.Info.MaxDC * (subType == 2 ? 1.50 : 1.30));
                    break;

                case MonsterRarity.Elite:
                    mob.Name = $"[统领]{mob.Info.GameName}";
                    mob.NameColour = Color.Gold;
                    mob.MaxHP = (uint)(mob.Info.HP * 5.5);
                    mob.MaxDC = (ushort)(mob.Info.MaxDC * 1.60);
                    mob.ActionTime = Math.Max(300, mob.Info.ActionTime - 140);
                    break;

                case MonsterRarity.Lord:
                    mob.Name = $"[领主]血煞{mob.Info.GameName}";
                    mob.NameColour = Color.Crimson; // 鲜血猩红，极度危险
                    mob.MaxHP = (uint)(mob.Info.HP * 9.0);
                    mob.MinDC = (ushort)(mob.Info.MinDC * 1.70);
                    mob.MaxDC = (ushort)(mob.Info.MaxDC * 1.95);
                    mob.ActionTime = Math.Max(250, mob.Info.ActionTime - 200);
                    mob.MoveSpeed = (ushort)Math.Max(350, mob.Info.MoveSpeed - 200);
                    mob.CoolEye = true; // 破除隐身术
                    break;
            }
            mob.HP = mob.MaxHP;
        }

        // 2. 红名 [领主] 两段式 AI（50%血量召唤亲卫 + 20%残血狂暴且禁绝自然回血）
        public static void OnMonsterTick(MonsterObject mob)
        {
            if (mob.Rarity != MonsterRarity.Lord || mob.Dead || mob.Target == null) return;

            // 阶段一：50% 血量召唤 2 只 [变异] 同族亲卫护驾，考验主号+Hero走位拉扯
            if (mob.PercentHealth <= 50 && !mob.LordGuardsSummoned)
            {
                mob.LordGuardsSummoned = true;
                for (int i = 0; i < 2; i++)
                {
                    var guard = MonsterObject.GetMonster(mob.Info);
                    if (guard != null)
                    {
                        OnMonsterSpawn(guard, MonsterRarity.Uncommon);
                        guard.Spawn(mob.CurrentMap, mob.CurrentLocation);
                        guard.Target = mob.Target;
                    }
                }
                if (mob.Target is PlayerObject p)
                    p.ReceiveChat($"⚠️ [领主咆哮] {mob.Name} 发出震天怒吼，召唤了 2 名变异亲卫前来护驾！", ChatType.System2);
            }

            // 阶段二：20% 血量困兽犹斗（攻速提升，但彻底封锁自然回血，防止单人近战打不死）
            if (mob.PercentHealth <= 20 && !mob.LordEnraged)
            {
                mob.LordEnraged = true;
                mob.ActionTime = Math.Max(200, mob.ActionTime - 80);
                mob.RegenTime = long.MaxValue; // 彻底锁死自然回血计时器！
                if (mob.Target is PlayerObject p)
                    p.ReceiveChat($"🔥 [困兽死斗] {mob.Name} 已陷入濒死狂暴，攻速激增，但已彻底丧失生命恢复能力！", ChatType.System2);
            }
        }

        // 3. 击杀怪物累积【地图惊扰度 (Map Heat)】并主动涌现精英/领主
        public static void OnMonsterKilled(MonsterObject mob, PlayerObject killer)
        {
            if (killer == null || mob.CurrentMap == null || mob.Rarity != MonsterRarity.None) return;

            Map map = mob.CurrentMap;
            int heat = MapHeatDict.TryGetValue(map, out int cur) ? cur : 0;
            heat += Envir.Main.Random.Next(3, 5); // 每杀1只普通怪 +3~4 点惊扰度

            if (heat >= 100) // 满 100 点：清零并在视野边缘刷出猩红 [领主]！
            {
                MapHeatDict[map] = 0;
                var lord = MonsterObject.GetMonster(mob.Info);
                if (lord != null)
                {
                    OnMonsterSpawn(lord, MonsterRarity.Lord);
                    lord.Spawn(map, mob.CurrentLocation);
                    killer.ReceiveChat($"🚨 【洞穴异动】你的持续杀戮彻底惊动了本层霸主——鲜红的 {lord.Name} 已在附近现身！", ChatType.System2);
                }
            }
            else if (heat >= 50 && heat - 4 < 50) // 刚突破 50 点：刷出一只 [精英]！
            {
                MapHeatDict[map] = heat;
                var rareMob = MonsterObject.GetMonster(mob.Info);
                if (rareMob != null)
                {
                    OnMonsterSpawn(rareMob, MonsterRarity.Rare);
                    rareMob.Spawn(map, mob.CurrentLocation);
                    killer.ReceiveChat($"⚡ 【气息躁动】当前区域惊扰度已达 {heat}/100，一只 {rareMob.Name} 被血腥味吸引而来！", ChatType.Hint);
                }
            }
            else
            {
                MapHeatDict[map] = heat;
            }
        }
    }
}
```

## 五、 专项三：客户端黑金铭牌遮罩 (`ChineseUIOverlay.cs`) —— 含 `SelectScene.cs` 创建角色与五职业面板完整实现

        // =========================================================================
        // 新增：选人场景与【创建角色 (五职业面板)】完整黑金遮罩实现
        // =========================================================================

        {
            if (scene == null) return;

            // 注：由于五职业按钮本身是精致的职业徽章图标，若不希望遮挡徽章图案，
            // 我们采用在每个职业按钮正下方挂载一块 42x16 的微型黑金标签，并联动选中高亮！
            AttachClassBadgeLabel(newCharDlg.WarriorButton, "战 士");
            AttachClassBadgeLabel(newCharDlg.WizardButton,  "法 师");
            AttachClassBadgeLabel(newCharDlg.TaoistButton,  "道 士");
            AttachClassBadgeLabel(newCharDlg.AssassinButton,"刺 客");
            AttachClassBadgeLabel(newCharDlg.ArcherButton,  "弓 箭");

            // 2.4 遮罩性别切换按钮文字（若需要）
            AttachClassBadgeLabel(newCharDlg.MaleButton,   "男", offsetY: 2);
            AttachClassBadgeLabel(newCharDlg.FemaleButton, "女", offsetY: 2);

            // 2.5 遮罩右侧/下方的【职业英文背景图说明区 (Class Description Box)】
            // 原版 .lib 背景图在职业说明区印有英文艺术字标题（如 "Warrior", "The Master of Sword"），
            // 我们直接创建一个带暗金边框的中文职业详情面板覆盖在该英文贴图区域上方，并在点击五职业按钮时动态切换文案！
            SetupDynamicClassDescriptionOverlay(newCharDlg);
        }

        /// <summary>
        /// 在职业/性别图标按钮底部边缘挂载微型中文标签（既保留原版职业徽章图案，又标明中文名称）
        /// </summary>
        private static void AttachClassBadgeLabel(MirButton btn, string cnName, int offsetY = 0)
        {
            if (btn == null) return;

            int badgeHeight = 15;
            var badge = new MirControl
            {
                Parent = btn,
                Size = new Size(btn.Size.Width - 2, badgeHeight),
                Location = new Point(1, btn.Size.Height - badgeHeight - 1 + offsetY),
                BackColour = Color.FromArgb(230, 18, 15, 12),
                DrawControlTexture = true,
                Border = true,
                BorderColour = PlaqueBorderColor,
                NotControl = true
            };

            var lbl = new MirLabel
            {
                Parent = badge,
                AutoSize = false,
                Size = badge.Size,
                Location = new Point(0, -1),
                DrawFormat = TextFormatFlags.HorizontalCenter | TextFormatFlags.VerticalCenter,
                ForeColour = ButtonTextColor,
                Font = new Font(Settings.FontName, 8F, FontStyle.Bold),
                Text = cnName,
                NotControl = true
            };

            btn.MouseEnter += (s, e) => lbl.ForeColour = ButtonHoverColor;
            btn.MouseLeave += (s, e) => lbl.ForeColour = ButtonTextColor;
        }

        /// <summary>
        /// 遮罩创建角色面板中的英文职业介绍背景图，并随五职业按钮点击实时切换中文流派说明
        /// </summary>
        private static void SetupDynamicClassDescriptionOverlay(SelectScene.NewCharacterDialog dlg)
        {
            // 若原版已经有一个 DescriptionLabel，我们先将其隐藏或直接接管其所在矩形区域
            // 标准 Euro Mir 创角窗口中，职业描述贴图区通常位于 (X: 25, Y: 215, Width: 245, Height: 95)
            // (提示：若你的皮肤坐标略有偏差，按住 Alt 键用内置坐标尺读一下左上角坐标填入此处即可)
            Rectangle descRect = dlg.DescriptionLabel != null
                ? new Rectangle(dlg.DescriptionLabel.Location.X - 6, dlg.DescriptionLabel.Location.Y - 22, 250, 105)
                : new Rectangle(25, 215, 250, 105);

            if (dlg.DescriptionLabel != null)
                dlg.DescriptionLabel.Visible = false; // 隐藏原有的英文/简陋文本，由黑金面板统一渲染

            var descBoard = new MirControl
            {
                Parent = dlg,
                Location = descRect.Location,
                Size = descRect.Size,
                BackColour = Color.FromArgb(248, 20, 17, 14), // 彻底盖住底图上的英文职业介绍艺术字
                DrawControlTexture = true,
                Border = true,
                BorderColour = PlaqueBorderColor,
                NotControl = true
            };

            // 顶部职业大标题 (如：【战 士 · 近战刚猛】)
            var classHeader = new MirLabel
            {
                Parent = descBoard,
                AutoSize = false,
                Size = new Size(descBoard.Size.Width - 12, 22),
                Location = new Point(6, 4),
                DrawFormat = TextFormatFlags.Left | TextFormatFlags.VerticalCenter,
                ForeColour = Color.Gold,
                Font = new Font(Settings.FontName, 9.5F, FontStyle.Bold),
                Text = "【战 士 · 刚猛重装】",
                NotControl = true
            };

            // 下方职业多行详细中文介绍
            var classBody = new MirLabel
            {
                Parent = descBoard,
                AutoSize = false,
                Size = new Size(descBoard.Size.Width - 16, descBoard.Size.Height - 30),

                NotControl = true
            };

            // 绑定五职业按钮点击事件，动态刷新中文标题与流派说明
            if (dlg.WarriorButton != null)
                dlg.WarriorButton.Click += (s, e) =>
                {
                    classHeader.Text = "【战 士 · 刚猛重装】";
                    classBody.Text = "精通刺杀剑术、烈火剑法、狮子吼与开天斩。\n体魄强健，擅长利用物理碰撞堵门抗怪，适合搭配【道士英雄】上毒辅助，或作为法师主号的坚实前排。";
                };

            if (dlg.WizardButton != null)
                dlg.WizardButton.Click += (s, e) =>
                {
                    classHeader.Text = "【法 师 · 元素毁灭】";
                    classBody.Text = "掌控火墙、冰咆哮、灭天火、分身术与流星火雨。\n拥有全服最恐怖的群体清图效率，且可诱惑5只契约魔宠；推荐搭配【战士或刺客英雄】顶前排抗领主。";

            if (dlg.TaoistButton != null)
                dlg.TaoistButton.Click += (s, e) =>
                {
                    classHeader.Text = "【道 士 · 万金油统帅】";
                    classBody.Text = "兼修红绿施毒术、幽灵盾、无极真气与噬血术。\n42级解锁双神兽、54级解锁三圣兽护体！单刷越级挑战红名【领主】最安逸的职业，亦是最佳辅助副将。";
                };

            if (dlg.AssassinButton != null)
                dlg.AssassinButton.Click += (s, e) =>
                {
                    classHeader.Text = "【刺 客 · 暗影双刃】";
                    classBody.Text = "全版本特色双持职业，精通鬼灵步、双剑合璧、霜月弯刀与月华乱舞。\n超高攻速与暴击机动性，配合【吸血/暴击】神话词条装备，化身贴身瞬秒精英怪的暗夜绞肉机。";
