# Crystal Mir2 游戏全栈汉化架构与实施方案

本文档汇总了 Crystal Mir2 客户端与服务端的完整汉化工程设计、多语言字典架构、C# 渲染层贴图遮罩技术与细节补漏规范。

---

## 一、 汉化工程目标与设计原则

### 1. 工程目标
* **玩家视野 100% 汉化**：UI 窗口、贴图按钮、悬浮提示（Tooltips）、聊天框系统消息、物品名、怪物名、地图名、技能名、NPC 对白与任务文本全中文。
* **运维与底层 0% 侵入**：`Server.exe` 后台管理 GUI 维持英文原版；音效（`Sound/`）保持原版；数据库内部唯一 Key（Name）保持原版，避免破坏怪物刷新、掉落与脚本引用。

### 2. 双轨制显示名称架构（解决“改名导致不爆装备”核心问题）
在传奇引擎中，`Server.MirDB` 里的 `ItemInfo.Name`、`MonsterInfo.Name` 与爆率文件（`Envir/Drops/*.txt`）、脚本指令（`GIVE`, `CHECKITEM`）是**强绑定的主键**。直接修改底层名称会导致掉落丢失或脚本失效。

本方案采用**“底层英文标识 + 前端/网络显示字典查表（Display Name）”**的双轨制架构：
* 底层数据流继续沿用原始名称（如 `WhiteEvilBoar`、`JudgementMace`）。
* 在客户端界面渲染、地面名字绘制、悬浮窗提示及网络通知包中，通过 `DbLanguage.cs` 动态映射为盛大经典中文（如 `白野猪`、`裁决之杖`）。

## 二、 多语言字典体系与文件职责

所有汉化数据均采用 JSON 格式组织，支持动态热切与无损维护：

| 字典文件 | 作用与覆盖范围 | 格式规范 |
| :--- | :--- | :--- |
| `Client/Localization/Chinese.json` | 客户端基础 UI、系统交互提示、按键说明、战斗提示、系统邮件署名 | 键值对 JSON（`"Key": "中文说明"`） |
| `Localization/DbLanguage.zh-CN.json` | 界面通用术语、装备分类、属性标签、职业与状态术语 | 分类映射 JSON |
| `Localization/ItemsMonsters.zh-CN.json` | 物品名、怪物名、地图名、技能名称与说明字典 | `{"Items": {}, "Monsters": {}, "Maps": {}, "Magics": {}}` |
| `Localization/NpcText.zh-CN.json` | NPC 名字、菜单选项、固定对白提示 | 中英映射表 |
| `Localization/NpcNarrative.zh-CN.json` | NPC 剧情叙事正文、任务对话段落 | 文本段落映射 |
| `Client/Localization/Overlay.zh-CN.json` | 免解包 .lib 贴图的 C# 渲染层黑金铭牌文字规则 | 贴图库名、帧索引、矩形坐标与文字配置 |

## 三、 免改 .lib 贴图・C# 渲染层“黑金铭牌遮罩”方案

### 1. 技术原理
客户端 UI 按钮与窗口标题很多是烘焙在 `Data/Title.Lib`、`Data/Prguse.Lib` 等二进制贴图库中的英文图片。为避免重新制作并分发数 GB 的素材包，同时防止贴图索引错位导致崩溃，采用**代码渲染层遮罩技术**：

* 利用 `MirControl` 原生支持的 `DrawControlTexture`（深褐底色）、`Border`（1像素暗金边框）以及 `NotControl = true`（鼠标事件 100% 穿透）。
* 在带英文的贴图区域上方，动态绘制一层仿原生风格的**黑金铭牌**（深褐底 + 暗金框 + 微软雅黑淡金文字）。
* **交互完整保留**：窗口标题栏仍可正常拖拽，按钮仍保留原生悬停高亮、按下位移与点击音效。

### 2. 集中接入架构
无需改动 20 多个 Dialog 类，直接在 `Client/MirControls/MirImageControl.cs` 的 `DrawControl()` 中集中拦截：
* 自动适配延迟创建的弹窗与动态切换贴图的按钮。
* 规则定义在 `Client/Localization/Overlay.zh-CN.json`，支持 93 条配置规则、166 个文字区域与 215 个贴图上下文映射。

### 3. 重点遮罩覆盖范围
* **人物与英雄面板**：装备、属性、状态、技能页签；25 项核心属性名称（防御、魔御、攻击力、魔法力、道术、体力、魔法、准确、敏捷等）。
* **背包与仓库**：包裹 1、包裹 2、任务物品页签，以及整理、添加按钮。
* **核心交互窗口**：登录、选人、创建角色、修改密码、系统设置、邮件、装备觉醒等窗口的标题与确定/取消按钮。
* **排版调试器**：客户端 INI 配置 `ChineseOverlayInspector=True` 可开启游戏内 Alt 坐标尺辅助微调。

## 四、 客户端宽屏视口与高清中文字体设定

### 1. 宽屏视口适配 (`1366 × 768`)
* **视口锁定**：客户端默认分辨率锁定为官方原生支持的宽屏 **`1366 × 768`（16:9）**，窗口化运行。
* **原生对齐**：此分辨率下 UI 布局、技能快捷栏、小地图及服务端 18 格视野数据范围（`DataRange`）天然对齐，无需魔改地图网格。
* **配置实现**：在 `Client/Settings.cs` 中默认设定，并在 `Mir2Config.ini` 的 `[Graphics]` 下持久化 `Resolution=1366`。

### 2. 高清中文字体渲染
* 将客户端默认字体由西文字体（`MS Sans Serif`）统一替换为 **`Microsoft YaHei`（微软雅黑）**。
* 消除中文字符发虚、锯齿以及部分 Windows 版本的“口口”方块字乱码。

## 五、 代码层显示死角汉化规范

1. **经典术语统一**：统一采用盛大经典译名，“持久”、“魔御”、“攻击”、“魔法力”、“道术”；准确区分“魔法力”（攻击属性）与“魔法值”（MP）。
2. **装备与道具悬浮窗 (Tooltips)**：
   * 修复材料与合成显示，优先读取 `FriendlyName`。
   * 觉醒属性等级与封顶标识汉化（`等级 / 极值`）。
3. **行会与社交**：
   * 行会权限设置、职位称号、行会增益（Buff）全中文展示。
   * 系统邮件署名采用中文本地化规则。
4. **宠物与召唤物**：
   * 宠物控制模式（攻击、跟随、守卫）中文状态提示。
   * 修复服务端召唤物上限与火墙回收提示的语言键泄露。
5. **大地图与任务**：
   * 大地图 NPC 标记名称查表显示为中文，保留内部地图 ID 便于运维定位。
   * 任务描述四个段落（目标、详情、交付、奖励）完整汉化。
